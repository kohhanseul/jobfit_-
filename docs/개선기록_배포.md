# 클라우드 배포 기록 (2026년 7월)

FastAPI, Docker에 이어 클라우드에 실제 배포해서 라이브 데모 링크 확보한 작업
라이브: https://p9kr69lbjsctwed7azrt66.streamlit.app/

## 문제

- 지금까지는 내 컴퓨터에서만 실행 -> 남이 보려면 내 컴퓨터가 켜져 있어야 함
- 배포 경험이 최대 갭이었음. 7월 작업(FastAPI, Docker)이 다 배포를 위한 준비였음
- 무료 클라우드엔 Ollama를 못 돌림 (GPU 없음, 메모리 부족) -> LLM/임베딩을 다른 방법으로

## 의사결정 1: 스토리 붕괴 피하기

- 처음엔 Gemini로 배포하려 함. 근데 이 프로젝트 스토리가 "비용 때문에 Gemini 버리고 Ollama로 감"인데 다시 Gemini로 가면 모순
- 재구성: 스토리의 핵심은 "Ollama"가 아니라 "상용 유료 API 대신 오픈소스 모델"
- -> 클라우드에서도 오픈모델을 무료로 호스팅해주는 Groq를 쓰면 스토리 유지됨
  (Gemini = 구글 비공개 모델 / Groq = 오픈소스 모델을 무료로 대신 돌려주는 서비스)

## 의사결정 2: 플랫폼도 검증 대상

- HF Spaces 시도 -> 정책이 바뀌어서 무료 파이썬 앱 호스팅이 사라짐
  (Static만 무료, Gradio/Docker는 유료로 전환됨)
- -> Streamlit Community Cloud로 전환. GitHub 저장소를 바로 읽어가서 오히려 더 간단
- 배운 것: 계획 세운 플랫폼도 막상 해보면 조건이 다를 수 있음. 유연하게 갈아탐

## 해결

**1. provider 전환 코드 (llm_provider.py)**
- GROQ_API_KEY 환경변수 유무로 로컬/클라우드 자동 전환
  - 로컬(키 없음): Ollama (bge-m3 + qwen3), 완전 오프라인
  - 클라우드(키 있음): e5-small(임베딩) + Groq(LLM)
- 앱 코드는 그대로. provider만 갈아끼움 (Docker에서 배운 환경변수 전환의 확장)

**2. 임베딩 교체 (메모리 대응)**
- bge-m3(2.3GB)가 Streamlit Cloud 메모리 초과 -> 가벼운 모델 테스트
- 후보 비교 (같은 평가셋 10문항)

| 모델 | 크기 | hit@1 | 채택 |
|---|---|---|---|
| paraphrase-multilingual-MiniLM | 470MB | 50% | X |
| multilingual-e5-small | 470MB | 90% | O |

- e5-small이 bge-m3와 동일한 90%. 단 e5 계열은 query:/passage: 프리픽스 필요 -> 코드에서 자동 부착

**3. 배포 전 Groq 키 사전 검증**
- 배포는 첫 빌드 5~10분이라, 배포 후 오류 발견하면 비쌈
- -> 로컬에서 Groq 호출 한 번 먼저 테스트 (키/모델명 정상 확인) 후 배포
- 느린 단계 전에 빠른 검증

**4. Secret으로 키 관리**
- 키를 코드에 적으면 GitHub에 노출 -> Streamlit Secret에만 등록
- 이 키의 존재가 곧 "클라우드 모드" 신호

## 결과

- 라이브 데모 URL 확보, 클라우드에서 e5-small + Groq 정상 동작
- 실제 자소서로 테스트: 관련 AI 공고 추천 + 경력/기술 불일치 공고는 이유와 함께 "부적합" 분리
- 배포 경험 갭 해소. 이력서에 "Streamlit Cloud 배포 (환경변수로 로컬/클라우드 provider 전환)" 추가 가능

## 남은 한계

- 할루시네이션 여전: 클라우드 LLM(Groq의 Llama)도 공고 우대사항(석사 우대)을 보고
  지원자가 석사 학위를 가진 걸로 지어냄. 로컬 qwen3와 같은 문제
  -> 소형/무료 모델의 공통 한계. 근거 인용 검증 단계가 다음 개선 방향

## 배운 것

- 스토리(오픈소스 vs 상용 API)를 지키면서 배포하는 방법이 있었음. Gemini만이 답이 아니었음
- 배포 플랫폼도 막상 하면 조건이 다름 (HF 정책 변경) -> 계획을 검증하고 갈아탐
- 모델을 바꾸면 그 모델의 학습 방식에 맞는 사용법도 바뀜 (e5 프리픽스)
- 느린 단계(배포) 전에 빠른 검증(Groq 로컬 테스트)으로 시간 절약
